# fileadeX Android 1.0.7 — build 25

- CSV, XLSX and XLS imports for Leads, Contacts and Accounts, with Manual / Import choices, file preview, column mapping, duplicate handling, upload/processing progress and import result review.

245 automated tests passed, with TypeScript and lint passing. Native Android release package, version, signing certificate, archive integrity, Maps key presence and embedded API/update-channel configuration are verified before publication.

This is not a claim that live-account import or complete physical-device journeys have passed acceptance testing. Purchases continue to use the existing eligible billing options. No iOS App Store publication is included in this Android update.

Use the production APK for existing production installations, or the separately labeled QA APK for QA installations. Android requires approval to install. Do not interchange signing channels.
